- 字段适配后，可将最终 176D 音频与 576D learned 视觉用于 concat / gated。保留 M3 320D 手工视觉版本作为对照。

### Sample ID 的目的与生成规则

项目仅使用 RAVDESS speech subset。跨模块 `sample_id` 是团队从官方文件名自动派生的共享录音标识，不是官方另外提供的字段；不需要逐条手动命名。它用于匹配同一录音的音频、视频、handcrafted 特征、learned 特征、标签和预测。

官方文件名七段结构：

```text
Modality-VocalChannel-Emotion-Intensity-Statement-Repetition-Actor
```

只删除第一段 Modality 和扩展名，保留其余六段的原始顺序和前导零：

```text
VocalChannel-Emotion-Intensity-Statement-Repetition-Actor

03-01-06-01-02-01-12.wav -> 01-06-01-02-01-12
01-01-06-01-02-01-12.mp4 -> 01-06-01-02-01-12
02-01-06-01-02-01-12.mp4 -> 01-06-01-02-01-12
```

团队提供的统一函数如下；所有成员应使用相同生成规则：

```python
from pathlib import Path


def generate_sample_id(filename):
    parts = Path(filename).stem.split("-")
    if len(parts) != 7 or any(
        len(part) != 2 or not part.isdigit() for part in parts
    ):
        raise ValueError("Expected a RAVDESS filename with seven two-digit fields.")
    if parts[1] != "01":
        raise ValueError("This project convention applies to speech samples only.")
    return "-".join(parts[1:])
```

当前运行代码 `fusion.data.trial_id` 已采用相同的六段生成规则，并额外检查字段取值和 neutral intensity。上面的 `generate_sample_id` 是文档中的团队参考函数，并未新增为可导入函数；现有代码继续调用 `trial_id`。

| 协议对齐 | 演员 ID、Sample ID 已确定；核对各模块遵循规范，并记录特征版本 | 全组使用同一接口 |
| 接口验证 | 让队友先导出少量样本，检查 pooled、概率、sequence 与长度 | 导出格式正确；正式校验再使用完整分组 |
| 工程验证 | 保留当前合成数据、检查乱序和缺失配对 | 自动测试通过 |
| 诊断准备 | 补验证集预测、gate、attention 诊断入口 | 能生成分析表，且不改变正常预测 |
| 模拟退化 | 音频变差、视觉变差、样本可靠性变化 | 推理无 NaN、结果可复现，诊断可观察变化 |

当前 `validate` 会检查 train/val/test 均覆盖八类，因此少量交接样本可先用 `load_pair` 检查格式；不能直接要求一个小样本包通过完整实验划分检查。

合成实验只检查工程行为；门控在模拟场景没有超过拼接，不应直接认定实现错误。不同模拟 seed 会改变生成数据；比较训练 seed 时必须固定同一份特征文件。

### 阶段 B 第 1～2 天 建立真实基线

| 编号 | 方法 | 输入 | 目的 |
|---|---|---|---|
| B1 | audio_only | 音频概率 | 原音频分类器基线 |
| B2 | visual_only | 视觉概率 | 原视觉分类器基线 |
| F1 | decision_equal | 两路概率 | 等权融合参照 |
| F2 | decision_tuned | 两路概率 | 验证集调权参照 |
| F3 | concat | 两路 pooled | 检查固定长度特征互补 |
| F4 | gated | 两路 pooled | 检查样本依赖门控收益 |
| F5 | cross_attention | 两路 sequence 和 lengths | 检查序列交互，序列可用时运行 |

统一起始配置：hidden=64、dropout=0.2、learning rate=0.001、batch size=64、epochs≤30、patience=8。Cross-attention 默认 4 heads；hidden 必须能被 heads 整除。

可训练融合本轮统一使用 seed=42、43、44（沿用当前团队记录规范），共 9 组默认配置。两路上游概率已固定时，不需要因融合 seed 不同而重复计算决策融合。

### 阶段 C 第 3 天 诊断并安排下一轮

先分析验证集：各方法 macro-F1、逐类 F1、训练/验证表现、四组单模态正确与错误样本、融合修复与破坏的数量。

| 观察到的结果 | 下一步实验 | 判断目标 |
|---|---|---|
| 决策融合优于单模态，复杂方法增益小 | 比较参数量、融合推理耗时和稳定性 | 是否选择简单方案 |
| 拼接优于概率融合 | 音频 pooled→MLP、视觉 pooled→MLP 控制 | 提升是否仅来自新分类头 |
| 门控在多个 seed 中优于拼接 | Gate 分组分析、质量退化实验 | 输入依赖权重是否有效 |
| Gate 几乎恒定 | 对比固定 gate/固定融合，检查特征尺度 | 动态门控是否有必要；恒定本身不是错误 |
| 训练损失下降而验证表现回落 | hidden 64→32，或 dropout 0.2→0.4 | 是否过拟合 |
| 训练和验证均较差 | 先检查标签与特征，再调整学习率/训练时长 | 是否接口错误或训练不足 |
| 两路错误高度重合 | 查看错误类别，讨论编码器改进 | 输入是否缺少互补信息 |
| Cross-attention 最好 | 音频序列均值池化 MLP、两路序列均值池化拼接 | 收益来自序列表示还是 attention |
| 单次很好、跨 seed 波动大 | 保留全部 seed，检查稳定性 | 是否偶然初始化优势 |
| 某类召回持续较低 | 样本数、混淆对、普通 CE 与加权 CE 对照 | 是否类别不平衡或类别特征不足 |

### 阶段 D 第 4～5 天 有针对性的小规模改进

每轮只改变一个主要因素，保留默认配置。先用 seed=42 筛选少量配置，再用其他两个 seed 复验选定配置。优先优化验证集上表现和稳定性较好的两种方法，避免大范围搜索。

可选候选：hidden=32、dropout=0.4、learning rate=0.0003。只有发现概率置信度差异明显时，才加入验证集温度校准；校准参数不能用测试数据拟合。

可预先采用工作量分配规则：验证 macro-F1 平均提升至少 0.02，且至少两个 seed 的改善方向一致，优先继续投入。0.02 是实用门槛，**不是统计显著性标准**。小幅差异可以结合运行成本与稳定性选择简单方案。

### 阶段 E 第 6～7 天 最终评价与解释

1. 锁定输入版本、方法配置、seed、checkpoint 选择规则、解释与案例选择规则。
2. 统一评价 held-out test，报告所有预先确定方法的指标。
3. 对可训练方法报告三个 seed 的均值与标准差；不挑测试最好的 seed。
4. 生成测试集解释图、成功/失败案例及局限讨论，不根据这些发现再次调同一个测试集。
5. 主实验不改变正式演员划分。若另行开展重复演员划分扩展，须先确认独立协议；两路编码器需随新划分重新训练与选择，不能仅重训融合头。

| 优先级 | 内容 | 训练成本 |
|---|---|---:|
| 必做，序列可用时 | 三种可训练融合 × 三个 seed | 9 次 |
| 必做控制 | 音频 pooled MLP、视觉 pooled MLP × 三个 seed | 6 次，待实现 |

## 5 结果解释方案

### 5.1 错误互补分析 必做

用两路单模态预测将样本分成：两路都对、只有音频对、只有视觉对、两路都错。对每种融合统计各组数量与正确率。

相对验证集选出的最强单模态，记录：

- 修复：单模态错误、融合正确。
- 破坏：单模态正确、融合错误。
- 保持正确、仍然错误。

推荐图：四组正确率柱状图、逐类 F1 改变量、修复/破坏统计。逐类比较应使用同一批样本。修复数减破坏数对应正确样本数变化，不能直接替代 macro-F1 的变化。

解释模板：融合的收益主要来自“只有视觉正确”的样本，但同时破坏了少量单模态正确的预测。必须由真实统计支持，不能预先假定视觉或音频擅长某种情绪。

### 5.2 模态干预与质量变化 必做

固定训练好的模型，不重新训练，比较正常输入与干预输入：

| 干预 | 实施方式 | 观察指标 |
|---|---|---|
| 音频替换 | 标准化后特征置零；如同时使用 sequence 也应明确处理范围 | F1、预测改变比例、固定目标类别概率变化 |
| 视觉替换 | 标准化后特征置零 | 同上 |
| 视觉错误配对 | 保留音频，替换为其他情绪样本的视觉 pooled/sequence/lengths 整组输入 | 对对应视觉情绪信息的敏感性 |
| 分级特征扰动 | 设置多个噪声级别、固定扰动 seed，重复推理 | 扰动强度—F1 曲线 |
| 原始输入退化，可选 | 音频加噪、视频降低亮度/遮挡后重新提取 | 对真实录制条件的稳健性 |

错误配对用于诊断时要在已配对的内存数据中实施，并保留原始清单；当前 loader 会按 ID 恢复配对，单纯打乱文件行顺序不会造成错误配对。每次扰动应同时保持视觉 sequence 与 lengths 对应，不允许产生无有效帧的序列。

重新训练的单模态控制回答“融合是否更有效”；固定模型的输入干预回答“当前模型对什么输入敏感”。特征置零和加噪可能超出训练分布，只能解释为干预敏感性，不能直接推断因果贡献比例。特征噪声也不能直接称为真实音频 SNR 或真实视频质量下降。

### 5.3 门控解释 门控保留时做

当前模型：

```text
h_a = tanh(W_a a + b_a)
h_v = tanh(W_v v + b_v)
g   = sigmoid(W_g [a; v] + b_g)
h   = g * h_a + (1-g) * h_v
logits = MLP(h)
```

Gate 是每个样本、每个隐藏维度的向量。可报告平均 gate 作为摘要，并展示其分布，但平均 gate=0.8 不能写成“音频贡献 80%”。投影表示的幅值和分类头都会影响最终输出。

建议图：按情绪的 gate 箱线图、按四组正确/错误样本的 gate 箱线图、同一样本退化前后的配对变化图。

将 gate 变化与干预结果联系起来：音频退化后 gate 是否向视觉移动？移动后预测是否更稳健？如果 gate 响应了，但性能未改善，应报告调整未产生有效补偿。跨 seed 分析先在各模型内比较，再汇总；隐藏维度之间不应直接逐维对应。

### 5.4 Attention 解释 有收益时做

导出每个 head 的 audio time step × visual frame attention。只展示有效位置，保留原始矩阵与平均摘要。若要对应到真实时间或画面，需要队友交付序列时间戳及采样信息，不能把 CNN 下采样后的每个 token 直接当作原始 MFCC 帧。

当前模型 `need_weights=False`，尚未导出 attention；诊断入口需显式返回权重并验证预测不变。

热力图用于展示内部关注模式，不能单独证明某帧导致了预测。增加：

1. 用有效视觉帧的均匀权重替代 learned attention；保持 V 投影、输出投影、音频 residual、LayerNorm 和分类头不变，再比较预测。
2. 扰动高 attention 帧表示，与相同数量随机帧的扰动比较。固定原预测目标类别，并重复随机对照。
3. 和不使用 attention 的序列均值池化控制模型比较。

当前融合层没有额外时间位置编码，同时重排视觉 K/V 的行不会改变聚合结果。因此简单打乱缓存视觉序列顺序不能检验该层是否利用时间顺序；如果要研究原始顺序，应在编码器输入阶段干预并重新提取特征。

参考：[Attention is not Explanation](https://aclanthology.org/N19-1357/)、[Attention is not not Explanation](https://aclanthology.org/D19-1002/)。这些研究主要来自 NLP，提供验证思路，不能替代本项目的音视频实证。

### 5.5 代表性案例 必做

先固定案例选择规则，例如每个组按 sample ID 排序选取前两个有效样本；没有样本的组报告数量为零，不临时改变规则。展示：视觉修正音频、音频修正视觉、融合破坏正确预测、全部失败。少量案例用于说明，不代表整体分布。

每个案例展示真实标签、两路和融合预测、八类概率、代表帧、gate 或 attention、干预后的变化。观察到的表情或声音特征可以描述，但“模型使用了这些特征”需要额外证据。

## 6 队友交接接口

每条模态交一个 `.npz`，字段如下：

| 字段 | 形状 | 说明 |
|---|---|---|
| sample_ids | [N] 字符串 | 不含 modality 的六段 trial ID |
| labels | [N] 整数 | 0～7 |
| actors | [N] 整数 | 1～24 |
| class_names | [8] 字符串 | 固定八类顺序 |
| pooled | [N,D] float32 | 选定完整表示 |
| probs | [N,8] float32 | 分类概率，每行和为 1，不能直接传 logits |
| sequence，可选 | [N,T,Ds] float32 | learned sequence，后部 padding |
| lengths，可选 | [N] 整数 | 有效时间步数，必须与 sequence 一起提供 |
| data_kind，可选 | 标量字符串 | 合成生成器写入 synthetic，程序自动标记合成运行 |

音频 pooled 为 proposal 规定的最终音频表示；视觉 pooled 为选出的 A、B 或 A+B。Sequence 来自选定 learned encoder，维度可与 pooled 不同。

例如 `03-01-06-01-02-01-12.wav` 与 `02-01-06-01-02-01-12.mp4` 对应 `01-06-01-02-01-12`。只去掉 modality；保留 intensity、statement、repetition 和 actor。

导出前将模型设为 eval，使用 inference_mode，Tensor 转为 NumPy。SVM 概率按 classes_ 重排到统一类别顺序。另交接编码器 checkpoint、预处理、训练演员、验证选择记录、时间戳等元数据。

当前三种模型分别为：

- concat：两路分别标准化后拼接，MLP 输出 8 类 logits。
- gated：独立投影、tanh、向量 gate 加权，再接 MLP。

MLP 为 Linear→ReLU→Dropout→Linear。训练为 AdamW，weight decay=1e-4，gradient clipping=1.0，普通 CrossEntropy。推理使用 softmax。缓存特征没有梯度，只有融合网络训练。

```python
"""Strict pairing by trial ID, actor partitioning and train-only normalization."""
import json
import re
from pathlib import Path
import numpy as np
from . import CLASSES


def trial_id(filename):
    """Drop only modality; retain vocal channel/emotion/intensity/statement/repetition/actor."""
    parts = Path(filename).stem.split('-')
    if len(parts) != 7 or any(not re.fullmatch(r'\d{2}', p) for p in parts):
        raise ValueError(f'Invalid RAVDESS filename: {filename}')
    modality, channel, emotion, intensity, statement, repetition, actor = map(int, parts)
    if modality not in (1, 2, 3) or channel not in (1, 2):
        raise ValueError(f'Invalid modality/channel: {filename}')
    if not (1 <= emotion <= 8 and intensity in (1, 2) and statement in (1, 2)
            and repetition in (1, 2) and 1 <= actor <= 24):
        raise ValueError(f'Invalid trial fields: {filename}')
    if channel != 1:
        raise ValueError(f'Song excluded: {filename}')
    if emotion == 1 and intensity != 1:
        raise ValueError(f'Neutral has normal intensity only: {filename}')
    return '-'.join(parts[1:])


def load_modality(path):
    with np.load(path, allow_pickle=False) as archive:
        d = {k: archive[k] for k in archive.files}
    required = {'sample_ids', 'labels', 'actors', 'class_names', 'pooled', 'probs'}
    if required - d.keys():
        raise ValueError(f'{path}: missing {sorted(required - d.keys())}')
    if tuple(d['class_names'].tolist()) != CLASSES:
        raise ValueError('class_names must follow the documented eight-class order')
    ids = d['sample_ids']
    n = len(ids)
    if n == 0 or ids.ndim != 1 or ids.dtype.kind not in 'US' or len(set(ids.tolist())) != n:
        raise ValueError('sample_ids must be unique nonempty strings')
    for k in ('labels', 'actors'):
        if d[k].shape != (n,) or d[k].dtype.kind not in 'iu':
            raise ValueError(f'{k} must be integer [N]')
    for sid, label, actor in zip(ids, d['labels'], d['actors']):
        if trial_id('03-' + str(sid) + '.wav') != sid:
            raise ValueError(f'Noncanonical sample ID {sid}')
        fields = list(map(int, str(sid).split('-')))
        if label != fields[1] - 1 or actor != fields[-1]:
            raise ValueError(f'Label/actor inconsistent with sample ID {sid}')
    if d['pooled'].ndim != 2 or d['pooled'].shape[0] != n or d['pooled'].shape[1] < 1:
        raise ValueError('pooled must be [N,D]')
    p = d['probs']
    if p.shape != (n, 8) or not np.isfinite(p).all() or (p < 0).any() or not np.allclose(p.sum(1), 1, atol=1e-4):
        raise ValueError('probs must be finite nonnegative [N,8] probabilities summing to one')
    if not np.isfinite(d['pooled']).all():
        raise ValueError('Nonfinite pooled features')
    if ('sequence' in d) != ('lengths' in d):
        raise ValueError('Provide sequence and lengths together')
    if 'sequence' in d:
        s, lengths = d['sequence'], d['lengths']
        if s.ndim != 3 or s.shape[0] != n or s.shape[2] < 1 or not np.isfinite(s).all():
            raise ValueError('sequence must be finite [N,T,D]')
        if lengths.shape != (n,) or lengths.dtype.kind not in 'iu' or (lengths < 1).any() or (lengths > s.shape[1]).any():
            raise ValueError('lengths must be integer [N] in 1..T')
    return d


def load_pair(audio_path, visual_path):
    a, v = load_modality(audio_path), load_modality(visual_path)
    if set(a['sample_ids'].tolist()) != set(v['sample_ids'].tolist()):
        raise ValueError('Modalities have different sample IDs; missing pairs must be resolved explicitly')
    lookup = {sid: i for i, sid in enumerate(v['sample_ids'])}
    order = np.array([lookup[sid] for sid in a['sample_ids']])
    v = {k: x[order] if k != 'class_names' and x.ndim and x.shape[0] == len(order) else x for k, x in v.items()}
    if not np.array_equal(a['labels'], v['labels']) or not np.array_equal(a['actors'], v['actors']):
        raise ValueError('Audio and visual labels/actors disagree')
    d = {k: a[k] for k in ('sample_ids', 'labels', 'actors')}
    kinds = {str(source.get('data_kind', 'unspecified')) for source in (a, v)}
    if len(kinds) != 1:
        raise ValueError('Audio and visual data_kind disagree')
    d['data_kind'] = kinds.pop()
    for prefix, source in (('audio', a), ('visual', v)):
        for k in ('pooled', 'probs', 'sequence', 'lengths'):
            if k in source:
                d[prefix + '_' + k] = source[k].astype(np.int64 if k == 'lengths' else np.float32)
    return d


def split_indices(d, config_path):
    split = json.loads(Path(config_path).read_text())
    if set(split) != {'train', 'val', 'test'}:
        raise ValueError('Partition must contain train, val, test')
    seen = set()
    for name, actors in split.items():
        if not actors or any(type(x) is not int or not 1 <= x <= 24 for x in actors):
            raise ValueError(f'Invalid actors in {name}')
        if len(actors) != len(set(actors)) or seen.intersection(actors):
            raise ValueError('Actor leakage/duplicate in partition')
        seen.update(actors)
    if set(d['actors'].tolist()) - seen:
        raise ValueError('Some samples have no partition')
    indices = {k: np.flatnonzero(np.isin(d['actors'], v)) for k, v in split.items()}
    for name, ix in indices.items():
        if not len(ix) or set(d['labels'][ix].tolist()) != set(range(8)):
            raise ValueError(f'{name} must contain samples of all eight classes')
    return indices, split


def fit_normalizers(d, train):
    stats = {}
    for k, x in d.items():
        if k.endswith('_pooled') or k.endswith('_sequence'):
            x = x[train]
            if k.endswith('_sequence'):
                lengths = d[k.replace('sequence', 'lengths')][train]
                x = x[np.arange(x.shape[1])[None, :] < lengths[:, None]]
            stats[k] = {'mean': x.mean(0).tolist(), 'std': np.maximum(x.std(0), 1e-6).tolist()}
    return stats


def normalize(d, stats):
    out = dict(d)
    for k, stat in stats.items():
        x = (d[k] - np.asarray(stat['mean'], np.float32)) / np.asarray(stat['std'], np.float32)
        if k.endswith('_sequence'):
            lengths = d[k.replace('sequence', 'lengths')]
            x = np.where((np.arange(x.shape[1])[None, :] < lengths[:, None])[..., None], x, 0)
        out[k] = x.astype(np.float32)
    return out
```

```python
import torch
from torch import nn


def head(dim, hidden, dropout):
    return nn.Sequential(nn.Linear(dim, hidden), nn.ReLU(), nn.Dropout(dropout), nn.Linear(hidden, 8))


class FusionModel(nn.Module):
    def __init__(self, method, audio_dim, visual_dim, audio_seq_dim=1, visual_seq_dim=1,
                 hidden=64, heads=4, dropout=0.2):
        super().__init__()
        self.method = method
        if method == 'concat':
            self.classifier = head(audio_dim + visual_dim, hidden, dropout)
        elif method == 'gated':
            self.audio = nn.Linear(audio_dim, hidden)
            self.visual = nn.Linear(visual_dim, hidden)
            self.gate = nn.Linear(audio_dim + visual_dim, hidden)
            self.classifier = head(hidden, hidden, dropout)
        elif method == 'cross_attention':
            if hidden % heads:
                raise ValueError('hidden must be divisible by heads')
            self.audio = nn.Linear(audio_seq_dim, hidden)
            self.visual = nn.Linear(visual_seq_dim, hidden)
            self.attention = nn.MultiheadAttention(hidden, heads, dropout=dropout, batch_first=True)
            self.norm = nn.LayerNorm(hidden)
            self.classifier = head(hidden, hidden, dropout)
        else:
            raise ValueError(f'Unknown model {method}')

    def forward(self, batch):
        if self.method == 'concat':
            return self.classifier(torch.cat([batch['audio_pooled'], batch['visual_pooled']], -1))
        if self.method == 'gated':
            a, v = batch['audio_pooled'], batch['visual_pooled']
            g = torch.sigmoid(self.gate(torch.cat([a, v], -1)))
            fused = g * torch.tanh(self.audio(a)) + (1 - g) * torch.tanh(self.visual(v))
            return self.classifier(fused)
        a, v = self.audio(batch['audio_sequence']), self.visual(batch['visual_sequence'])
        mask_v = torch.arange(v.shape[1], device=v.device)[None, :] >= batch['visual_lengths'][:, None]
        mask_a = torch.arange(a.shape[1], device=a.device)[None, :] < batch['audio_lengths'][:, None]
        context, _ = self.attention(a, v, v, key_padding_mask=mask_v, need_weights=False)
        sequence = self.norm(a + context)
        pooled = (sequence * mask_a[..., None]).sum(1) / batch['audio_lengths'][:, None]
        return self.classifier(pooled)
```

```python
import copy
import csv
import json
import platform
import random
from pathlib import Path
import numpy as np
import torch
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix, f1_score
from . import CLASSES
from .data import load_pair, split_indices, fit_normalizers, normalize
from .models import FusionModel


def seed_all(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.set_num_threads(2)
    torch.use_deterministic_algorithms(True)


def tensor_batch(d, ix, device):
    return {k: torch.as_tensor(x[ix], device=device) for k,x in d.items()
            if k.startswith(('audio_', 'visual_')) and not k.endswith('_probs')}


@torch.no_grad()
def infer(model, d, ix, device, batch_size=64):
    model.eval()
    return np.concatenate([model(tensor_batch(d, ix[j:j+batch_size], device)).softmax(-1).cpu().numpy()
                           for j in range(0, len(ix), batch_size)])


def metrics(y, probs):
    pred = probs.argmax(1)
    return {'accuracy': float(accuracy_score(y, pred)),
            'macro_f1': float(f1_score(y, pred, labels=range(8), average='macro', zero_division=0)),
            'per_class': classification_report(y, pred, labels=range(8), target_names=CLASSES,
                                               output_dict=True, zero_division=0),
            'confusion_matrix': confusion_matrix(y, pred, labels=range(8)).tolist()}


def write_json(path, value):
    Path(path).write_text(json.dumps(value, indent=2, ensure_ascii=False) + '\n')


def run(audio, visual, split_path, output, methods, epochs=30, batch_size=64, lr=.001,
        hidden=64, heads=4, dropout=.2, patience=8, seed=42, device='cpu', synthetic=False):
    if epochs < 1 or batch_size < 1 or patience < 1 or lr <= 0:
        raise ValueError('epochs, batch_size, patience and lr must be positive')
    output = Path(output)
    if (output / 'metrics.json').exists():
        raise ValueError('Output already contains a run; choose a new --output to preserve results')
    output.mkdir(parents=True, exist_ok=True)
    (output / 'checkpoints').mkdir(exist_ok=True)
    seed_all(seed)
    raw = load_pair(audio, visual)
    synthetic = synthetic or raw.get('data_kind') == 'synthetic'
    indices, actors = split_indices(raw, split_path)
    if 'cross_attention' in methods and 'audio_sequence' not in raw:
        raise ValueError('cross_attention requires audio sequences')
    if 'cross_attention' in methods and 'visual_sequence' not in raw:
        raise ValueError('cross_attention requires visual sequences')
    train, val, test = (indices[k] for k in ('train', 'val', 'test'))
    normalizers = fit_normalizers(raw, train)
    d = normalize(raw, normalizers)
    config = dict(audio_dim=raw['audio_pooled'].shape[1], visual_dim=raw['visual_pooled'].shape[1],
                  audio_seq_dim=raw.get('audio_sequence', np.empty((0,0,1))).shape[-1],
                  visual_seq_dim=raw.get('visual_sequence', np.empty((0,0,1))).shape[-1],
                  hidden=hidden, heads=heads, dropout=dropout)
    report = {'synthetic': synthetic, 'seed': seed, 'actors': actors,
              'counts': {k: len(v) for k,v in indices.items()}, 'class_names': list(CLASSES),
              'environment': {'python': platform.python_version(), 'numpy': np.__version__, 'torch': str(torch.__version__)},
              'settings': dict(epochs=epochs, batch_size=batch_size, lr=lr, patience=patience, device=device, **config),
              'inputs': {'audio': str(Path(audio).resolve()), 'visual': str(Path(visual).resolve())},
              'models': {}}
    predictions = {}
    for name, key in [('audio_only', 'audio_probs'), ('visual_only', 'visual_probs')]:
        report['models'][name] = {part: metrics(d['labels'][ix], d[key][ix]) for part, ix in [('val', val), ('test', test)]}
        predictions[name] = d[key][test]
    if 'decision' in methods:
        def mix(alpha, ix):
            return alpha * d['audio_probs'][ix] + (1-alpha) * d['visual_probs'][ix]
        grid = [dict(alpha=float(a), macro_f1=metrics(d['labels'][val], mix(a,val))['macro_f1'])
                for a in np.linspace(0,1,21)]
        # Ties favor the least departure from equal weighting.
        winner = max(grid, key=lambda row: (row['macro_f1'], -abs(row['alpha']-.5)))
        for name, alpha in [('decision_equal', .5), ('decision_tuned', winner['alpha'])]:
            report['models'][name] = {'alpha_audio': alpha, 'val': metrics(d['labels'][val], mix(alpha,val)),
                                      'test': metrics(d['labels'][test], mix(alpha,test))}
            predictions[name] = mix(alpha,test)
            write_json(output / 'checkpoints' / f'{name}.json', {'method':'decision', 'alpha_audio': alpha, 'class_names': list(CLASSES)})
        write_json(output / 'decision_validation_grid.json', grid)
    histories = {}
    for method in methods:
        if method == 'decision':
            continue
        seed_all(seed)
        model = FusionModel(method, **config).to(device)
        opt = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=1e-4)
        best, best_epoch, stale, best_state = -1, 0, 0, None
        history = []
        for epoch in range(1, epochs+1):
            model.train()
            order = np.random.permutation(train)
            loss_sum = 0.
            for j in range(0, len(order), batch_size):
                ix = order[j:j+batch_size]
                opt.zero_grad()
                logits = model(tensor_batch(d, ix, device))
                loss = torch.nn.functional.cross_entropy(logits, torch.as_tensor(d['labels'][ix], device=device))
                if not torch.isfinite(loss):
                    raise ValueError(f'Nonfinite loss in {method}')
                loss.backward()
                torch.nn.utils.clip_grad_norm_(model.parameters(), 1.)
                opt.step()
                loss_sum += loss.item() * len(ix)
            score = metrics(d['labels'][val], infer(model,d,val,device,batch_size))['macro_f1']
            history.append({'epoch':epoch, 'train_loss':loss_sum/len(train), 'val_macro_f1':score})
            if score > best + 1e-8:
                best, best_epoch, stale = score, epoch, 0
                best_state = copy.deepcopy(model.state_dict())
            else:
                stale += 1
            if stale >= patience:
                break
        model.load_state_dict(best_state)
        checkpoint = {'method':method, 'config':config, 'state_dict':best_state,
                      'normalizers':normalizers, 'class_names':list(CLASSES), 'actors':actors,
                      'synthetic':synthetic, 'best_epoch':best_epoch}
        torch.save(checkpoint, output / 'checkpoints' / f'{method}.pt')
        report['models'][method] = {'best_epoch':best_epoch,
                                   'val':metrics(d['labels'][val], infer(model,d,val,device,batch_size)),
                                   'test':metrics(d['labels'][test], infer(model,d,test,device,batch_size))}
        predictions[method] = infer(model,d,test,device,batch_size)
        histories[method] = history
        print(f'{method}: best epoch={best_epoch}, validation macro-F1={best:.4f}', flush=True)
    # Choose by validation only. Test scores are descriptive comparisons, not selection inputs.
    selected = max(report['models'], key=lambda k:report['models'][k]['val']['macro_f1'])
    baseline = max(('audio_only','visual_only'), key=lambda k:report['models'][k]['val']['macro_f1'])
    report['selected_by_validation'] = selected
    report['strongest_unimodal_by_validation'] = baseline
    report['selected_test_delta_vs_baseline'] = report['models'][selected]['test']['macro_f1'] - report['models'][baseline]['test']['macro_f1']
    write_json(output / 'metrics.json', report)
    write_json(output / 'history.json', histories)
    with (output / 'summary.csv').open('w',newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['model','val_macro_f1','test_macro_f1','test_accuracy'])
        for name,row in report['models'].items():
            writer.writerow([name, row['val']['macro_f1'], row['test']['macro_f1'], row['test']['accuracy']])
    with (output / 'test_predictions.csv').open('w',newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['sample_id','label','model','prediction',*CLASSES])
        for name,probs in predictions.items():
            for sid,label,p in zip(d['sample_ids'][test], d['labels'][test],probs):
                writer.writerow([sid, int(label), name, int(p.argmax()), *p.tolist()])
    # Inspectable complete split assignment, shared with teammates.
    with (output / 'split_manifest.csv').open('w',newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['sample_id','actor','label','split'])
        for part,ix in indices.items():
            writer.writerows(zip(d['sample_ids'][ix], d['actors'][ix], d['labels'][ix], [part]*len(ix)))
    render_confusions(report, output)
    return report

def predict(checkpoint_path, audio, visual, output, device='cpu'):
    d = load_pair(audio,visual)
    if str(checkpoint_path).endswith('.json'):
        ck = json.loads(Path(checkpoint_path).read_text())
        if tuple(ck['class_names']) != CLASSES:
            raise ValueError('Checkpoint class order mismatch')
        alpha = ck['alpha_audio']
        probs = alpha*d['audio_probs'] + (1-alpha)*d['visual_probs']
    else:
        ck = torch.load(checkpoint_path, map_location=device, weights_only=True)
        if tuple(ck['class_names']) != CLASSES:
            raise ValueError('Checkpoint class order mismatch')
        model = FusionModel(ck['method'], **ck['config']).to(device)
        model.load_state_dict(ck['state_dict'])
        d = normalize(d,ck['normalizers'])
        probs = infer(model,d,np.arange(len(d['labels'])),device)
    rows = [{'sample_id':str(sid), 'emotion':CLASSES[int(p.argmax())],
             'confidence':float(p.max()), 'probabilities':dict(zip(CLASSES,map(float,p)))}
            for sid,p in zip(d['sample_ids'],probs)]
    write_json(output,rows)
    return probs
```

```python
"""Synthetic, class-correlated features for integration tests, never research evidence."""
from pathlib import Path
import numpy as np
from . import CLASSES


def generate(directory, seed=42):
    directory = Path(directory)
    directory.mkdir(parents=True, exist_ok=True)
    rng = np.random.default_rng(seed)
    # Full speech trial structure: 60 recordings per actor; neutral has one intensity.
    trials = [(a, e, intensity, s, r) for a in range(1, 25) for e in range(8)
              for intensity in ([1] if e == 0 else [1, 2]) for s in (1, 2) for r in (1, 2)]
    ids = np.array([f'01-{e+1:02d}-{i:02d}-{s:02d}-{r:02d}-{a:02d}' for a,e,i,s,r in trials])
    labels = np.array([t[1] for t in trials], dtype=np.int64)
    actors = np.array([t[0] for t in trials], dtype=np.int64)
    n = len(trials)
    # Different noisy class prototypes, actor nuisance and sample-specific modality corruption.
    for modality, dim, seq_dim, time, noise in [('audio', 32, 24, 12, 1.5), ('visual', 40, 28, 16, 1.7)]:
        prototype = rng.normal(size=(8, dim))
        seq_proto = rng.normal(size=(8, seq_dim))
        actor_shift = rng.normal(scale=.4, size=(24, dim))
        reliability = rng.choice([.7, 2.6], size=n, p=[.75, .25])
        pooled = prototype[labels] + actor_shift[actors-1] + rng.normal(size=(n, dim)) * reliability[:, None]
        logits = rng.normal(scale=noise, size=(n, 8))
        logits[np.arange(n), labels] += 2.5
        probs = np.exp(logits - logits.max(1, keepdims=True))
        probs /= probs.sum(1, keepdims=True)
        lengths = rng.integers(time // 2, time + 1, size=n)
        sequence = seq_proto[labels, None, :] + rng.normal(scale=1.5, size=(n, time, seq_dim))
        sequence[np.arange(time)[None, :] >= lengths[:, None]] = 0
        # Deliberately shuffle visual rows to exercise ID-based pairing.
        order = rng.permutation(n) if modality == 'visual' else np.arange(n)
```

```python
def canonical_classes(names):
    names = tuple('surprise' if str(x) == 'surprised' else str(x) for x in names)
    if names != CLASSES:
        raise ValueError('Unexpected class order; refusing implicit probability reordering')
    return np.asarray(CLASSES)


def import_archive(archive, destination):
    destination = Path(destination)
    destination.mkdir(parents=True, exist_ok=True)
    source_root = destination / 'source'
    source_root.mkdir(exist_ok=True)
    with zipfile.ZipFile(archive) as z:
        # Read data only; never import or execute content from the supplied archive.
        for info in z.infolist():
            target = (source_root / info.filename).resolve()
            if not target.is_relative_to(source_root.resolve()):
                raise ValueError('Unsafe archive path')
            if (info.external_attr >> 16) & 0o170000 == 0o120000:
                raise ValueError('Symlink archive member rejected')
            if info.is_dir():
                target.mkdir(parents=True, exist_ok=True)
            else:
                target.parent.mkdir(parents=True, exist_ok=True)
                target.write_bytes(z.read(info))
    source = source_root / 'm5_learned_feature_only'
    metadata = json.loads((source/'metadata.json').read_text())
    canonical_classes(metadata['class_names'])
    with (source/'manifest.csv').open() as f:
        rows = list(csv.DictReader(f))
    if len(rows) != 1440 or len({r['sample_id'] for r in rows}) != 1440:
        raise ValueError('Expected 1440 unique trials')
    actors, sequence_summary, converted = {}, {}, {}
    seen_actors = set()
    for split, expected_n in [('train',960),('val',240),('test',240)]:
        subset = [r for r in rows if r['split'] == split]
        if len(subset) != expected_n:
            raise ValueError(f'Unexpected count for {split}')
        actors[split] = sorted({int(r['actor_id']) for r in subset})
        if seen_actors.intersection(actors[split]):
            raise ValueError('Source actor leakage')
        seen_actors.update(actors[split])
        by_id = {r['sample_id']:r for r in subset}
        with np.load(source/'pooled'/f'{split}.npz',allow_pickle=False) as z:
            classes = canonical_classes(z['class_names'])
            ids = z['sample_ids'].copy()
            if set(ids.tolist()) != set(by_id) or len(ids) != len(by_id):
                raise ValueError('Manifest/pooled IDs mismatch')
            if not np.all(z['splits'] == split):
                raise ValueError('Pooled split mismatch')
            d = dict(sample_ids=ids,labels=z['labels'].copy(),actors=z['actor_ids'].copy(),
                     class_names=classes, pooled=z['F_audio_learned_feature_only'].copy(),
                     probs=z['P_audio_learned_feature_only'].copy(),data_kind=np.array('real_m2_learned_only'))
        if d['pooled'].shape != (expected_n,128):
            raise ValueError('Unexpected audio feature dimensions')
        lengths = []
        for i,sid in enumerate(ids):
            row = by_id[str(sid)]
            if trial_id('03-'+str(sid)+'.wav') != sid:
                raise ValueError('Invalid trial ID')
            expected_path = f'per_sample/{split}/{sid}.npz'
            if row['feature_file'] != expected_path:
                raise ValueError('Unexpected sample path')
            with np.load(source/expected_path,allow_pickle=False) as sample:
                canonical_classes(sample['class_names'])
                if (str(sample['sample_id']) != sid or str(sample['split']) != split
                    or int(sample['actor_id']) != int(row['actor_id'])):
                    raise ValueError('Sample metadata mismatch')
                if not (int(sample['actor_id']) == int(d['actors'][i]) == int(row['actor_id'])):
                    raise ValueError('Actor mismatch')
                if not (int(sample['label']) == int(d['labels'][i]) == int(row['label'])):
                    raise ValueError('Label mismatch')
                s, mask, length = sample['F_sequence'], sample['padding_mask'], int(sample['length'])
                if s.ndim != 2 or s.shape[1] != 128 or not np.isfinite(s).all():
                    raise ValueError('Bad sequence')
                if mask.dtype != np.bool_ or mask.shape != (len(s),) or not 1 <= length <= len(s):
                    raise ValueError('Bad mask/length')
                if not np.array_equal(mask,np.arange(len(s)) >= length) or length != int(row['length']):
                    raise ValueError('Padding convention/length mismatch')
                np.testing.assert_allclose(sample['F_audio_learned_feature_only'], d['pooled'][i],atol=1e-6)
                np.testing.assert_allclose(sample['P_audio_learned_feature_only'], d['probs'][i],atol=1e-6)
                lengths.append(length)
        path = destination/f'audio_{split}.npz'
        np.savez_compressed(path,**d)
        load_modality(path)
        converted[split] = path
        sequence_summary[split] = {'count':expected_n,'min_length':min(lengths),'max_length':max(lengths),
                                   'mean_length':float(np.mean(lengths)),
                                   'class_counts':np.bincount(d['labels'],minlength=8).tolist()}
    if seen_actors != set(range(1,25)):

def pilot(archive, destination, output, epochs=20, seed=42):
    started=time.monotonic()
    output=Path(output)
    if (output/'validation_metrics.json').exists():
        raise ValueError('Choose a new output directory to preserve prior results')
    output.mkdir(parents=True,exist_ok=True)
    paths,audit=import_archive(archive,destination)
    # Inspecting test format above is an integrity audit only. No test prediction or metric.
    train,val=load_modality(paths['train']),load_modality(paths['val'])
    seed_all(seed)
    mean=train['pooled'].mean(0)
    std=np.maximum(train['pooled'].std(0),1e-6)
    x=torch.from_numpy((train['pooled']-mean)/std)
    xv=torch.from_numpy((val['pooled']-mean)/std)
    y=torch.as_tensor(train['labels'],dtype=torch.long)
    model=head(128,64,.2)
    opt=torch.optim.AdamW(model.parameters(),lr=.001,weight_decay=1e-4)
    history=[]
    best=-1
    best_state=None
    stale=0
    for epoch in range(1,epochs+1):
        model.train()
        loss_sum=0.
        for ix in torch.randperm(len(x)).split(64):
            opt.zero_grad()
            loss=torch.nn.functional.cross_entropy(model(x[ix]),y[ix])
            if not torch.isfinite(loss):
                raise ValueError('Nonfinite training loss')
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(),1.)
            opt.step()
            loss_sum+=float(loss.detach())*len(ix)
        model.eval()
        with torch.no_grad():
            p=model(xv).softmax(-1).numpy()
        score=metrics(val['labels'],p)['macro_f1']
        history.append({'epoch':epoch,'train_loss':loss_sum/len(x),'val_macro_f1':score})
        if score>best+1e-8:
            best,best_epoch,stale=score,epoch,0
            best_state={k:v.detach().clone() for k,v in model.state_dict().items()}
        else:
            stale+=1
        if stale>=8:
            break
    model.load_state_dict(best_state)
    model.eval()
    with torch.no_grad():
        new_probs=model(xv).softmax(-1).numpy()
    results={'scope':'Real M2 learned-only audio; validation-only pilot; no visual fusion',
             'seed':seed,'requested_epochs':epochs,'completed_epochs':len(history),'best_epoch':best_epoch,
             'actors':audit['actors'],'test_metrics_computed':False,

                         'patience':8,'device':'cpu','frozen_encoder':True},
             'elapsed_seconds':time.monotonic()-started}
    torch.save({'state_dict':best_state,'mean':torch.tensor(mean),'std':torch.tensor(std),
                'class_names':list(CLASSES),'input_dim':128,'hidden':64,'dropout':.2,
                'best_epoch':best_epoch,'seed':seed,'model_type':'audio_only_mlp'},output/'audio_pooled_mlp.pt')
    # Verify the saved checkpoint reproduces the validation prediction.
    ck=torch.load(output/'audio_pooled_mlp.pt',weights_only=True,map_location='cpu')
    restored=head(128,ck['hidden'],ck['dropout']).eval()
    restored.load_state_dict(ck['state_dict'])

        restored_probs=restored((torch.from_numpy(val['pooled'])-ck['mean'])/ck['std']).softmax(-1).numpy()
    np.testing.assert_allclose(restored_probs,new_probs,atol=1e-6)

    for key in ['upstream_audio','retrained_audio_pooled_mlp']:
```

```python
"""Feature-only handoff adapter. Test features and upstream probabilities are excluded."""
import csv
import hashlib
import zipfile
from pathlib import Path
import numpy as np
from . import CLASSES
from .data import trial_id


def sha256(path):
    with Path(path).open('rb') as f:
        return hashlib.file_digest(f, 'sha256').hexdigest()


def selected_npz_rows(path, key, indices):
    """Decode only requested rows of a C-contiguous .npy member, never unpickle.

    Zip seeks may decompress skipped bytes internally, but skipped rows are never
    decoded as arrays or returned to the experiment. No upstream probs are read.
    """
    indices = np.asarray(indices, dtype=np.int64)
    if len(indices) == 0 or (np.diff(indices) <= 0).any():
        raise ValueError('Row indices must be nonempty, unique and ascending')
    with zipfile.ZipFile(path) as archive, archive.open(key + '.npy') as f:
        version = np.lib.format.read_magic(f)
        shape, fortran, dtype = np.lib.format._read_array_header(f, version)
        if fortran or dtype.hasobject or not shape or indices[0] < 0 or indices[-1] >= shape[0]:
            raise ValueError('Unsupported array format or row indices')
        start = f.tell()
        row_size = int(np.prod(shape[1:], dtype=np.int64)) * dtype.itemsize
        out = np.empty((len(indices), *shape[1:]), dtype=dtype)
        for j, i in enumerate(indices):
            f.seek(start + int(i) * row_size)
            buf = f.read(row_size)
            if len(buf) != row_size:
                raise ValueError('Truncated array')
            out[j] = np.frombuffer(buf, dtype=dtype).reshape(shape[1:])
    return out


def load_development_features(audio_csv, audio_sequences, visual_npz, actor_csv,
                              expected_counts=None):
    """Only train/val numeric features are decoded; no test file is opened."""
    if expected_counts is None:
        expected_counts = {'train': 960, 'val': 240}
    with Path(actor_csv).open() as f:
        rows = list(csv.DictReader(f))
    actor_map = {int(r['actor_id']): r['split'] for r in rows}
    if len(rows) != 24 or set(actor_map) != set(range(1,25)):
        raise ValueError('Expected 24 unique actors')
    if any(x not in ('train','val','test') for x in actor_map.values()):
        raise ValueError('Unknown actor split')
    # Only IDs and splits are read across the whole visual file to select dev rows.
    with np.load(visual_npz, allow_pickle=False) as z:
        all_ids, all_splits = z['sample_id'], z['split']
    if len(set(all_ids.tolist())) != len(all_ids):
        raise ValueError('Duplicate visual IDs')
    visual_ix = np.flatnonzero(np.isin(all_splits, ['train','val']))
    visual_ids = all_ids[visual_ix]
    visual_splits = all_splits[visual_ix]
    labels = selected_npz_rows(visual_npz, 'label', visual_ix)
    pooled = selected_npz_rows(visual_npz, 'pooled_features', visual_ix)
    sequence = selected_npz_rows(visual_npz, 'sequence_features', visual_ix)
    if pooled.shape != (len(visual_ix),576) or sequence.shape != (len(visual_ix),16,576):
        raise ValueError('Expected MobileNet 576D pooled and 16x576 sequence')
    visual = {}
    for j,(sid,split,label) in enumerate(zip(visual_ids, visual_splits, labels)):
        sid = str(sid)
        if trial_id('03-' + sid + '.wav') != sid:
            raise ValueError('Invalid canonical visual ID')
        if int(label) != int(sid.split('-')[1])-1 or actor_map[int(sid[-2:])] != split:
            raise ValueError('Visual label or split mismatch')
        visual[sid] = (j, str(split), int(label))
    audio = {}
    with Path(audio_csv).open() as f:
        reader = csv.DictReader(f)
        metadata = {'sample_id','trial_id','actor_id','emotion_label','split'}
        feature_keys = [k for k in reader.fieldnames if k not in metadata]
        if len(feature_keys) != 176:
            raise ValueError('Expected 176 combined audio features')
        for row in reader:
            if row['split'] not in ('train','val'):
                continue  # Do not convert/consume test feature values.
            sid = trial_id(row['sample_id'])
            lab = CLASSES.index('surprise' if row['emotion_label']=='surprised' else row['emotion_label'])
            if actor_map[int(row['actor_id'])] != row['split'] or int(sid[-2:]) != int(row['actor_id']):
                raise ValueError('Audio actor/split mismatch')
            if int(sid.split('-')[1])-1 != lab or sid in audio:
                raise ValueError('Audio label mismatch or duplicate ID')
            audio[sid] = (np.asarray([float(row[k]) for k in feature_keys],np.float32),row['split'],lab)
    if set(audio) != set(visual):
        raise ValueError('Development audio/visual sample IDs differ')
    ids = sorted(audio)
    audio_seq, lengths, opened_paths = [], [], []
    for sid in ids:
        ax, split, lab = audio[sid]
        j, vsplit, vlabel = visual[sid]
        if (split,lab) != (vsplit,vlabel):
            raise ValueError('Cross-modal label/split mismatch')
        path = Path(audio_sequences)/split/f'{sid}.npz'
        # Path is derived exclusively from train/val records.
        with np.load(path,allow_pickle=False) as z:
            seq, length, mask = z['F_sequence'], int(z['length']), z['padding_mask']
            if str(z['sample_id']) != sid or str(z['split']) != split or int(z['label']) != lab:
                raise ValueError('Audio sequence metadata mismatch')
            if int(z['actor_id']) != int(sid[-2:]):
                raise ValueError('Audio sequence actor mismatch')
            if seq.shape != (length,128) or length < 1 or mask.dtype != np.bool_ or mask.shape != (length,) or mask.any():
                raise ValueError('Unexpected audio sequence/mask')
            if not np.allclose(seq.mean(0),ax[48:],atol=1e-5):
                raise ValueError('Audio sequence and combined learned feature mismatch')
            audio_seq.append(seq.copy()); lengths.append(length)
        opened_paths.append(path)
    maxlen = max(lengths)
    padded = np.zeros((len(ids),maxlen,128),np.float32)
    for i,s in enumerate(audio_seq):
        padded[i,:len(s)] = s
    order = np.asarray([visual[s][0] for s in ids])
    d = {'sample_ids':np.asarray(ids), 'labels':np.asarray([audio[s][2] for s in ids],np.int64),
         'actors':np.asarray([int(s[-2:]) for s in ids],np.int64),
         'splits':np.asarray([audio[s][1] for s in ids]),
         'audio_pooled':np.stack([audio[s][0] for s in ids]),'visual_pooled':pooled[order],
         'audio_sequence':padded, 'visual_sequence':sequence[order],
         'audio_lengths':np.asarray(lengths,np.int64),'visual_lengths':np.full(len(ids),16,np.int64)}
    for key in ('audio_pooled','visual_pooled','audio_sequence','visual_sequence'):
        if not np.isfinite(d[key]).all():
            raise ValueError('Nonfinite development features: '+key)
    for split,n in expected_counts.items():
        ix = d['splits']==split
        if ix.sum()!=n or set(d['labels'][ix].tolist())!=set(range(8)):
            raise ValueError('Unexpected development counts/classes: '+split)
    source_hashes = {'audio_csv':sha256(audio_csv),'visual_npz':sha256(visual_npz),
                     'actor_csv':sha256(actor_csv)}
    sequence_digest = hashlib.sha256()
    for path in opened_paths:
        sequence_digest.update(path.name.encode())
        sequence_digest.update(bytes.fromhex(sha256(path)))
    source_hashes['ordered_train_val_audio_sequences'] = sequence_digest.hexdigest()
    audit = {'counts':{s:int((d['splits']==s).sum()) for s in ('train','val')},
             'test_status':'not_run', 'test_numeric_rows_decoded':0, 'upstream_probabilities_loaded':False,
             'audio_sequence_files_opened':len(opened_paths),'audio_sequence_splits_opened':['train','val'],
             'source_hashes':source_hashes,
             'notes':['Whole-file IDs/splits used for routing only; only train/val feature rows decoded.',
                      'Shared CSV/NPZ checksums cover whole source containers, not model evaluation.',
                      'Visual 16 tokens treated as valid as supplied; upstream lengths/mask provenance unconfirmed.',
                      'Audio pooled=48 handcrafted+128 learned; attention audio sequence is learned-only 128D.',
                      'Upstream probability order unconfirmed; probability arrays intentionally never loaded.']}
    return d,audit
```

```python
def run(audio_csv, audio_sequences, visual_npz, actor_csv, output, epochs=30,
        patience=8, seed=42, batch_size=64, hidden=64, heads=4, dropout=.2, lr=.001):
    if min(epochs,patience,batch_size,hidden,heads)<1 or hidden%heads or lr<=0 or not 0<=dropout<1:
        raise ValueError('Invalid training parameters')
    output=Path(output)
    if output.exists() and any(output.iterdir()):
        raise ValueError('Use a fresh output directory')
    output.mkdir(parents=True,exist_ok=True)
    started=datetime.now().astimezone().isoformat();clock=time.monotonic()
    raw,audit=load_development_features(audio_csv,audio_sequences,visual_npz,actor_csv)
    write_json(output/'adapter_audit.json',audit)

    with (output/'input_manifest.csv').open('w',newline='') as f:
        w=csv.writer(f);w.writerow(['sample_id','actor_id','split','label'])
        w.writerows(zip(raw['sample_ids'],raw['actors'],raw['splits'],raw['labels']))
    train=np.flatnonzero(raw['splits']=='train');val=np.flatnonzero(raw['splits']=='val')
    stats=fit_normalizers(raw,train)
    d=normalize(raw,stats)
    config=dict(audio_dim=176,visual_dim=576,audio_seq_dim=128,visual_seq_dim=576,
                hidden=hidden,heads=heads,dropout=dropout)
    settings=dict(epochs=epochs,patience=patience,seed=seed,batch_size=batch_size,lr=lr,
                  optimizer='AdamW',weight_decay=1e-4,gradient_clip=1.,device='cpu',**config)
    report={'scope':'Real frozen-feature fusion pilot, train/validation only',
            'started_at':started,'test_status':'not_run','test':None,'decision_fusion':'deferred',
            'seed':seed,'settings':settings,'counts':audit['counts'],'class_names':list(CLASSES),
            'environment':{'python':platform.python_version(),'torch':str(torch.__version__),
                           'numpy':np.__version__,'sklearn':sklearn.__version__,'device':'cpu'},
            'assumptions':audit['notes'],'source_hashes':audit['source_hashes'],'models':{}}
    snapshot=output/'code';snapshot.mkdir()
    for name in ('__init__.py','feature_inputs.py','feature_pilot.py','models.py','data.py','experiment.py'):
        source=Path(__file__).with_name(name)
        (snapshot/name).write_bytes(source.read_bytes())
    write_json(output/'code_hashes.json',{p.name:sha256(p) for p in snapshot.iterdir()})
    for method in ('concat','gated','cross_attention'):
        seed_all(seed)
        folder=output/method;folder.mkdir()

        opt=torch.optim.AdamW(model.parameters(),lr=lr,weight_decay=1e-4)
        best=-1.;best_state=None;stale=0;history=[];t0=time.monotonic()
        for epoch in range(1,epochs+1):

            for j in range(0,len(train),batch_size):

                if not torch.isfinite(loss):

        np.testing.assert_allclose(infer(restored,d,val,'cpu',batch_size),probs,rtol=1e-5,atol=1e-6)
        m=val_metrics(d['labels'][val],probs)
        row={'best_epoch':best_epoch,'completed_epochs':len(history),'val':m,'test':None,
             'test_status':'not_run','parameters':sum(p.numel() for p in model.parameters()),
             'training_seconds':time.monotonic()-t0,'checkpoint_roundtrip_verified':True}
        report['models'][method]=row
        write_json(folder/'metrics.json',row);write_json(folder/'history.json',history)
        with (folder/'predictions_val.csv').open('w',newline='') as f:
            w=csv.writer(f);w.writerow(['sample_id','actor_id','split','label','prediction',*CLASSES])

        record_run(folder,method,row,settings,audit,output,started,report['environment'])

    report['selected_by_validation']=max(report['models'],key=lambda k:report['models'][k]['val']['macro_f1'])
    report['elapsed_seconds']=time.monotonic()-clock

    return report
```

本节是检索与实验候选设计，尚未新增训练。仍固定旧特征、不接WavLM；后续只用train/val开发，保持测试暴露记录。下面“建议实现”均为本项目改造方案，不能称为完整复现原论文；论文其他数据集的成绩不是本项目目标或提升保证。

### 优先1：监督对比学习（SupCon）

论文：Khosla等，Supervised Contrastive Learning，NeurIPS2020。[原论文页面](https://proceedings.neurips.cc/paper_files/paper/2020/hash/d89a66c7c80a29b1bdbab0f2a1a94af8-Abstract.html)

原理是利用标签拉近同类别嵌入、分开不同类别。本项目辅助CE在三个seed都改善普通残差，值得继续研究表示学习目标，而非只改attention。

建议：在既有audio_residual_aux或同投影concat上，加小型64D projection head；比较原CE/辅助CE与额外SupCon。第一版只给一个固定损失权重如0.1、temperature0.1（本项目起始配置，非原论文最佳配置）；先做模态内同情绪约束，再决定是否跨模态。构造同情绪、不同训练演员的正样本可作为本项目扩展。

必须避免把同一情绪的其他样本都当负例；batch无有效正例的anchor需跳过。只用train标签构造对比集合，验证样本不能进入训练memory bank。强制把质量差的视觉与音频贴近可能产生负迁移，需保留模态特有表示与音频控制。SupCon原论文不是本项目RAVDESS音视频协议，不能直接推断跨演员提升。

### 优先2：低秩乘性交互（LMF，前次已提及，本次明确实验方案）

论文：Liu等，Efficient Low-rank Multimodal Fusion With Modality-Specific Factors，ACL2018。[原论文](https://aclanthology.org/P18-1209/)

它用低秩因子近似张量交互，以较少参数表达模态间的乘性组合。可先做176D音频/576D视觉各投影64D，固定rank4，输出64D再接同MLP。rank8留待rank4有依据后追加。

至少保留“同样投影+concat”控制与原concat：若只和raw concat比较，不能区分收益来自投影还是乘性交互。记录实际参数量和推理时间。LMF是模型族，不能把任意逐元素乘法都称作原LMF复现；实现时需照原公式保留低秩因子与单模态项。

### 优先3：共享/特有信息分解（MISA）

论文：Hazarika等，MISA: Modality-Invariant and -Specific Representations for Multimodal Sentiment Analysis，ACM MM2020。[原论文全文](https://arxiv.org/html/2005.03545v3)

原模型为各模态同时学习shared和private表示，并用相似性、差异、重建与任务损失约束。它不要求所有信息都跨模态相同，适合检验当前简单对齐是否压掉视觉/音频各自的有效信号。

建议简化版：音频与视觉各投影64D，再各分32D共享/32D特有；将四个向量拼接接分类头。依次对照：仅分支结构、加共享相似性、加差异/重建损失，而非一次把所有loss加上。完整原论文含三模态与其fusion设计，此二模态简化版明确标注MISA-inspired。

“shared/private”是结构上的分解，不能自动证明语义已可解释或去除了身份信息。过强分布对齐可能损伤真正互补的特征，不能只看两个模态可视化是否重合。

### 优先4：小数据强基线，多核学习（SimpleMKL思想）

论文：Rakotomamonjy等，SimpleMKL，JMLR2008。[原论文](https://www.jmlr.org/beta/papers/v9/rakotomamonjy08a.html)

为音频/视觉分别建立核，再学习核组合与SVM。现有960训练录音可先比较单模态线性/RBF SVM、拼接SVM、双模态核融合，以检查当前MLP是否是分类头瓶颈。

可用K=alpha*K_audio+(1-alpha)*K_visual作为简化对照；若alpha只是固定小网格选择，应称kernel fusion，不能称完整SimpleMKL优化。核归一化及所有scaler仅在train拟合，搜索预算固定。该方法的核权重是全局量，不代表样本级贡献或因果重要性。算法没有随机初始化时不需伪造三seed重复。

### 质量融合与解释：QMF及可靠性打乱诊断

论文：Zhang等，Provable Dynamic Fusion for Low-Quality Multimodal Data，ICML2023，提出Quality-aware Multimodal Fusion（QMF）。[原论文](https://proceedings.mlr.press/v202/zhang23ar.html)

其重点是可靠的不确定性估计与动态权重，而非任意softmax confidence加权；文中理论依赖不确定性与单模态损失的关系，不是任意实现都有不劣于单模态的保证。值得检验：当视觉模糊/缺失时权重能否下降，视觉可靠而音频有误时能否修复。

重要接口限制：原方法energy使用分类器logits。仅有概率不能唯一恢复logits；直接把log(p)当logits，在T=1时logsumexp(log(p))=0，energy成为常数。我们可从自有MLP checkpoint重新导出验证logits；不能伪造上游未提供的原logits。简单entropy gate可以作为额外基线，但不是原QMF复现。应先验证可靠性与错误/损失的关系，再训练更复杂router。

近期解释论文：Moon等，When Does Quality-Aware Multimodal Fusion Matter? A Leakage-Safe Diagnostic for Decision-Level Dependence，2026；作者arXiv页面记录已接收INTERSPEECH2026。[作者原稿](https://arxiv.org/abs/2606.26473)

可直接借鉴低成本诊断：冻结模型、固定音视频输入，记录原可靠性；仅在验证样本间打乱可靠性分数，重复固定随机排列，比较原权重/常数权重/打乱权重下的预测变化率、目标概率和F1。如果结果几乎不变，不能仅凭gate图声称模型在按质量选模态；但也可能是两路本来预测一致或权重变化不足，需检查正控制和冲突样本。原论文的具体数据结论不能直接推广到我们。

当前gate由输入内部生成，因此需增加“覆盖gate但固定特征”的推理接口；这与此前错配视觉特征实验不同。用真值确定哪一路正确的oracle只能作诊断上界/正控制，不能混入正式可部署预测。此项在验证集开展，不新增测试评估。

### 跨演员扩展：身份对抗（DANN思想）

论文：Ganin等，Domain-Adversarial Training of Neural Networks，JMLR2016。[原论文](https://www.jmlr.org/beta/papers/v17/15-239.html)

在可训练投影后增actor分类器与gradient reversal，使主任务保留情绪判别、同时抑制训练actor可辨识信息。可先用actor probe检查特征是否包含身份，再对比有/无actor对抗。actor probe能预测身份不代表一定依赖身份做情绪判断。

原DANN是源/目标域适应；把16个训练演员当多个域且不使用val/test训练，是本项目domain-generalization改造，不是原方法的直接复现。对抗loss过强会删除情绪信息；actor分类准确率下降本身也可能由表示坍缩引起，必须同时检查情绪F1、特征方差及演员分组表现。不因actor17的测试低分为该演员定制规则。

### 暂低优先级的方法

- OGM-GE：Peng等，Balanced Multimodal Learning via On-the-Fly Gradient Modulation，CVPR2022。[原论文](https://openaccess.thecvf.com/content/CVPR2022/html/Peng_Balanced_Multimodal_Learning_via_On-the-Fly_Gradient_Modulation_CVPR_2022_paper.html)。调节模态分支优化，适合可训练分支；冻结编码器无法通过梯度修复其已导出表征，冻结音频残差组也不能直接照搬。若仅作用于adapter，需标注改造并先测模态梯度/学习差异。
- MBT：Nagrani等，Attention Bottlenecks for Multimodal Fusion，NeurIPS2021。[原论文](https://proceedings.neurips.cc/paper/2021/hash/76ba9f564ebbc35b1014ac498fafadd0-Abstract.html)。以少量latent tokens限制跨模态信息交换，可做1层/4token轻量候选；其原论文大规模音视频训练成绩不能保证960条训练录音上的收益。先不继续扩展Transformer搜索。
- EmbraceNet：Choi与Lee，2019。[作者原稿](https://arxiv.org/abs/1904.09078)。适用于部分模态缺失，随机坐标级融合不同于整条视觉dropout；但本项目目前完整配对，优先级低于解决干净验证表现与数据来源。
- DCCA：Andrew等，ICML2013。[原论文](https://proceedings.mlr.press/v28/andrew13.html)。最大化跨视图相关性可作表示对齐参照，但相关信号可能是演员/句子而非情绪，不能把相关性提高当任务改善。

### 建议的下一轮最小清单（尚未执行）

1. 一个低成本解释诊断：gate/可靠性重排，对比固定gate和原gate；无需重训。
2. 两个主要神经候选：LMF rank4；在当前辅助CE基础上加SupCon。配同投影、同分类头对照，各3seed，保持有限配置。
3. 一个分类器家族控制：固定预算的SVM/核融合，判断换分类头是否比改attention有效。
4. 只有前三项明确指向表征缺口，再投入MISA或actor对抗；不要同时叠加所有loss。

所有候选预先记录假设、控制、预算和判定门槛；继续只看验证集。若训练actor内做完整OOF评估，上游有监督编码器/adapter、scaler也必须按fold重训；不能用已见全部训练演员标签的缓存冒充完整actor-held-out结果。以上为候选实验设计，本次文献搜索未训练新候选。
