# Course submission guide

The local Practice Module handout specifies one team ZIP submitted to Canvas by **31 October 2026**, with individual reflections and peer review submitted separately.

## System materials

| Material | Location |
|---|---|
| Runnable audio, visual, fusion and demonstration code | Repository modules and `project.py` |
| Operating instructions and environments | `docs/operation-guide.md`, dependency files |
| Trained models and final feature inputs | Separate model ZIP; feature inputs generated locally |
| Metrics, predictions, comparisons and explanations | `docs/results.md` and linked experiment records |
| Group report | `submission_documents/Group13_Final_Report.docx` |
| Available proposal / M5 slides | `submission_documents/` |

## Additional course materials

The handout also calls for datasets, slides from both presentations and a 10–15 minute presentation video. The local files supplied for this packaging task include the proposal slides and M5 fusion slides. Raw datasets, the presentation recording and a final combined team deck are not included in the code/results ZIP; add them to the team's Canvas delivery as applicable. Dataset retrieval instructions are in `docs/delivery.md`.

Each member's 1–2 page reflection and peer review are separate submissions. A GitHub repository link accompanies the system but does not replace the specified Canvas ZIP.

The handout is preserved locally as `For FT students only (excluding Aramco students)/PRS-PatternRecognitionSystems-Practice-Module 7.0 - FT.pdf` (submission requirements on pages 8, 9, 15 and 16).
