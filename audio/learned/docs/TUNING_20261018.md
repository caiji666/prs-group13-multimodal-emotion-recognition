## Changes made before each experiment

All five experiments preserve CNN/BiLSTM/Transformer topology, 40D MFCC inputs, 128D sequence/pooled outputs and eight logits. Changes are training hyperparameters, classifier dropout and per-encoder initialization; no encoder architecture or preprocessing changes.

### Experiment 1

Small-step refinement from the actual latest Transformer winner; reduce potential smoothing/class-weight overcorrection; preserve best historical CNN/BiLSTM parents. Validation only; no test decoding.

- learning_rate: 5e-5 -> 2e-5
- weight_decay: .001 -> .0005
- head_dropout: .25 -> .20
- label_smoothing: .05 -> 0
- class_balance_power: .5 -> .25
- epochs: 15 -> 20
- patience: 5 -> 7

Initialization: `"runs/tuning_20261018/initialization"`.

### Experiment 2

Round01 matched baseline only and showed training/validation gap. Restore per-encoder best parents; stronger regularization/augmentation and larger LR to move out of local plateau.

- learning_rate: 2e-5 -> 1e-4
- weight_decay: .0005 -> .003
- head_dropout: .20 -> .35
- label_smoothing: 0 -> .10
- class_balance_power: .25 -> .5
- augment_probability: .5 -> .75
- epochs: 20 -> 16
- patience: 7 -> 5

Initialization: `{"cnn": "runs/tuning_20261018/initialization", "bilstm": "runs/tuning_20261018/initialization", "transformer": "runs/tuning_20261018/initialization"}`.

### Experiment 3

Round02 stronger joint updates regressed Transformer. Preserve its best features with a small backbone LR while allowing classifier boundary adaptation; revert stronger regularization. All parents selected by validation best including original baseline.

- encoder_learning_rate: uniform1e-4 -> 5e-6
- head_learning_rate: uniform1e-4 -> 1e-4 (20x encoder)
- weight_decay: .003 -> .001
- head_dropout: .35 -> .25
- label_smoothing: .10 -> .05
- augment_probability: .75 -> .5
- epochs: 16 -> 20
- patience: 5 -> 6

Initialization: `{"cnn": "runs/tuning_20261018/initialization", "bilstm": "runs/tuning_20261018/initialization", "transformer": "runs/tuning_20261018/initialization"}`.

### Experiment 4

Round03 improved CNN slightly but classifier adaptation did not surpass Transformer baseline. Reduce classifier step size, use smaller batches and new initialization/dropout/batch/augmentation randomness; actor split remains identical. Warm start from best prior validation parents.

- seed: 42 -> 7
- batch_size: 32 -> 16
- head_learning_rate: 1e-4 -> 2e-5
- encoder_learning_rate: 5e-6 unchanged
- epochs: 20 -> 16
- patience: 6 -> 5

Initialization: `{"cnn": "runs/tuning_20261018/initialization", "bilstm": "runs/tuning_20261018/initialization", "transformer": "runs/tuning_20261018/initialization"}`.

### Experiment 5

Round04 slightly improved F1 but not accuracy. Continue from its Transformer winner; restore batch32 and use augmented-only training plus mild smoothing/dropout increase to counter the persistent train/validation gap, with a new seed. CNN/BiLSTM start from their own best historical checkpoints. Preserve original/fourth-round winners if this round regresses.

- seed: 7 -> 17
- batch_size: 16 -> 32
- encoder_learning_rate: 5e-6 -> 1e-5
- head_learning_rate: 2e-5 unchanged
- augment_probability: .5 -> 1.0
- label_smoothing: .05 -> .10
- head_dropout: .25 -> .30
- epochs: 16 -> 20
- patience: 5 -> 7

Initialization: `{"cnn": "runs/tuning_20261018/initialization", "bilstm": "runs/tuning_20261018/initialization", "transformer": "runs/tuning_20261018/round_04"}`.

## Code and artifact integrity

- train.py adds optional encoder_learning_rate/head_learning_rate parameter groups. Existing configs without these keys retain the original single-group AdamW path. Added validation and a regression test; 29 tests passed.
- Original best checkpoint and numerical model/data/inference/feature reader source files unchanged; new results are kept separately.
- Recomputed all 15 saved validation prediction tables (240 records each) and matched saved accuracy/Macro-F1. Best checkpoint passed current export provenance checks.
- No test metrics, no video processing, no Git commit/push and no new M1/M5 feature delivery generated.
- Different seeds affect initialization/dropout/shuffling/augmentation, not actor assignments. These are adaptive single-split experiments, not independent repeated test estimates.
