# Experiment decisions and interpretation

## What changed before each experiment

1. **Round 01:** Switch the new branch from MFCC input to frozen WavLM Base+ representations of mono 16 kHz waveforms. Trim boundary silence at top_db=35; follow the pinned official processor (`do_normalize=false`), without the legacy peak-normalization step. Use layer 12 temporal mean, train-only fitted feature standardization, input dropout 0.1, Linear(768,128)/LayerNorm/GELU adapter and Linear(128,64)/ReLU/Dropout(0.3)/Linear(64,8) head. AdamW learning rate 0.001, weight decay 0.01, batch 32, maximum 80 epochs, patience 12, label smoothing 0.05, square-root inverse-frequency class weights. Best epoch 18 of 30 completed.
2. **Round 02:** Keep Round 01 training settings, replace temporal mean with concatenated mean and population standard deviation, widening adapter input to 1536. Train from a new initialization. Best epoch 43 of 55 completed.
3. **Round 03:** Keep Round 02 statistics/adapter/head/training; add three learned softmax weights mixing standardized pooled statistics from layers 6, 9 and 12. Train from a new initialization. Final selected checkpoint mixture weights were 0.420799, 0.289777 and 0.289424, making layer 6 strongest. Best epoch 13 of 25 completed. A mixture of statistics is not the standard deviation of a mixed temporal sequence.
4. **Round 04:** Based on Round 03, select frozen layer 6. Replace the pooled adapter with a framewise 768→128 projection/LayerNorm/GELU and masked attention (128→64→1). Pool weighted mean and standard deviation; project 256→128, then use the existing 128→64→8 head structure. Fit frame normalization on clean training frames only. Learning rate becomes 0.0005, maximum epochs 60, patience 10; pooled input dropout is unused/0. Train from a new initialization. Best epoch 16 of 26 completed.
5. **Round 05:** Warm-start Round 04's selected adapter/head; create a new optimizer. Keep architecture and layer 6, add training-only mixup (alpha=0.2) to pooled learned vectors, set learning rate 0.0002, weight decay 0.02, head dropout 0.4, label smoothing 0.02, maximum epochs 50 and patience 10. Best epoch 6 of 16 completed.

All rounds use seed 42, gradient clipping 1.0, ReduceLROnPlateau factor 0.5/patience 4, and class balance power 0.5. Cross-entropy consumes logits; softmax is used for saved probabilities. Evaluation disables augmentation/dropout. WavLM parameters remain frozen, including in Round 05. Cached upstream hidden states are quantized to float16 then converted back to float32 for training; raw-audio inference reproduces that quantization.

## Evidence and limits

The best model correctly predicts 195/240 validation examples, compared with the old baseline's 131/240. Accuracy increases by 26.6667 percentage points; Macro-F1 increases by 27.3455 percentage points. Each experiment's metrics were independently recomputed from saved probability CSVs. The best model was additionally rerun from all 240 original validation WAVs and reproduced those predictions. Unit tests check adapter shapes, gradients, checkpoint restoration and temporal padding invariance.

This improvement uses a different input representation and extensive external speech pretraining. It is not a same-input, from-scratch architecture-only comparison with the old MFCC models. The official upstream card lists Libri-Light, GigaSpeech and VoxPopuli; this branch does not download an emotion-finetuned RAVDESS model. Repeated adaptation to the same validation actors can overfit the validation set. No test-set evaluation, multi-seed estimate or unseen-corpus claim is made. Final held-out testing remains separate from model selection.

Only these five formal configurations were trained in this branch. Frozen feature extraction, unit tests, and independent inference checks are not additional training runs. The existing CNN/BiLSTM/Transformer were preserved rather than retrained. The legacy selected checkpoint and existing M1/M5 handoff files remain unchanged; this research winner is stored separately and has not been promoted automatically.
